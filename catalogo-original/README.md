# Catálogo original (fuente)

Guarda aquí las exportaciones de Canva **sin modificarlas**:

- `catalogo.pdf`: PDF estándar del catálogo.
- `paginas/`: PNG de cada página (`pagina-01.png`, `pagina-02.png`, …).
- `fotos/`: fotografías originales de los productos.
- `logo.*`: logotipo.

Estos archivos son la referencia para verificar nombres, textos, precios y colores. El sitio no los usa directamente: las versiones optimizadas van a `assets/`.
